- organization_detail_screen.dart: simplemente se ha añadido un chip con un label y un color, por lo que NO ha sido necesario usar IA.
- task_detail_screen.dart: simplemente se ha añadido un label, por lo que NO ha sido necesario usar IA.
- main_wrapper_screen.dart: se ha utilizado IA para añadir Kanban al bottomnavigationbar, pues no he logrado entender cómo funciona el sistema de navegación que diseñaron mis compañeros.
